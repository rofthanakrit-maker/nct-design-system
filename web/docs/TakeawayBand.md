The one-line conclusion strip. Every table slide and every diagram slide must
carry one — the reader has to get the point without reading the grid.

One place, one look: pass `foot` so it pins to the bottom of the body box, the
same y on every slide. It is always tinted with an accent label — there is no
dark variant. The layouts that carry a strip (03, 05, 06, 09, 11–14, 16, 18,
19, 21–26) already place it; reach for `TakeawayBand` directly only when
composing a slide from `Slide` + `SlideTitle`.
